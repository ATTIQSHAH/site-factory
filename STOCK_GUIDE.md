# Stock library (replaces Pexels API)
Create these folders in GitHub (Add file > Create new file, type the path, e.g. sites/_stock/coffee/README.txt):
  sites/_stock/coffee/       coffee shops and cafes
  sites/_stock/bakery/       bakeries, desserts, cakes
  sites/_stock/grill/        BBQ, burgers, pizza, tacos, pubs
  sites/_stock/restaurant/   everything else (dining rooms, plated food)
In each folder put:
  - 8 to 12 landscape photos (JPG/WEBP, 1600 to 1920 px wide, under 400 KB each; compress at squoosh.app)
  - 1 to 3 videos named hero1.mp4, hero2.mp4 (10 to 20 s, 1280x720, no sound needed, under 6 MB)
Pick generic, correct images (a latte for coffee, a dining room for restaurants). Avoid close-ups of a specific dish unless it fits every lead in that folder.
Sources you can browse without any API key: pexels.com, unsplash.com, pixabay.com (check each licence before use).
Rules: the tool uses a lead's own photos first and fills the gaps from these folders; a different image order per lead.
